# Tracker App 🎯

Мобильное приложение для iOS, которое помогает пользователям формировать полезные привычки и контролировать их выполнение ежедневно. Проект выполнен в рамках учебной программы **Яндекс Практикум**.

---

## 📌 Назначение и цели

Приложение разработано для комплексного управления личной продуктивностью.

**Основные цели проекта:**
* Контроль выполнения привычек с привязкой к дням недели.
* Наглядный мониторинг личного прогресса и успехов с помощью детальной статистики.

---

## 📱 Краткое описание функционала

* **Гибкие трекеры:** Создание карточек двух типов — регулярных привычек (с расписанием) и нерегулярных событий (без привязки к дням).
* **Кастомизация:** Для каждого трекера можно выбрать уникальное имя, категорию, цвет и эмодзи.
* **Календарь и фильтры:** Быстрый просмотр запланированных задач на любой выбранный день с возможностью поиска и фильтрации (по завершенным, незавершенным, или трекерам на сегодня).
* **Категории:** Сортировка трекеров по группам, управление категориями (добавление, редактирование, удаление, закрепление карточек).
* **Аналитика:** Экран статистики, отражающий ключевые метрики вовлеченности пользователя (лучший период, идеальные дни, завершенные трекеры).

## 🛠 Технические и системные требования

| Параметр | Требование |
| :--- | :--- |
| **Минимальная версия iOS** | iOS 17.0+ *(укажите ваш реальный Deployment Target, если он ниже)* |
| **Язык программирования** | Swift |
| **Архитектурный паттерн** | MVVM *(или MVC — выберите один актуальный)* |
| **Интерфейс** | UIKit (Полностью программно / Programmatic UI, без Storyboards) |
| **База данных** | Core Data (локальное хранение привычек и истории) |
| **Основной шрифт** | SF Pro (системный) |
| **Дизайн** | Поддержка Темной и Светлой тем (Dark/Light Mode) |


## 🚀 Инструкция по запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Yandex-Practicum/iOS-TrackerApp-Public.git
   ```
2. Откройте файл проекта в Xcode 15+ (`TrackerApp.xcodeproj` или `TrackerApp.xcworkspace`).
3. Выберите симулятор (например, iPhone 15/16 на базе iOS 17.0 или новее).
4. Нажмите `Cmd + R` для сборки и запуска приложения.
